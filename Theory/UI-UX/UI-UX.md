**I Дизайн не ради дизайна**  
Декоратор делает красиво, дизайнер решает с помощью определенных инструментов в дизайне конкретную проблему  
~Проблематика первична~  

- Какую проблему решает твой дизайн? Целесообразность, исследования до проектирования
- выбираем определенные аспекты дизайна для решения конкретно твоей проблемы, только важные
- учитываем, что некоторые вещи пользователь может использовать не так как ты задумывал или вообще для чего-то другого  
    ~Готовые решения не решают ТВОЮ проблему~  
    
- только для практики и набивки руки
- для исследований и размышлений. Почему эту дизайнеры применили именно такое решение? Какую проблему они решали?

**II Принцип единства**

- то, что связывает элементы интерфейса воедино
- нужно видеть работу как единое целое
- мало использовать все принципы дизайна, нужно использовать конкретные для усиления эффекта решения задачи
- необходимо создать ui-kit - набор инструментария, который будет необходим для решения поставленной задачи
- набор экранов должен использовать этот инструментарий

**III Принцип баланса**  
используя принцип баланса можно управлять вниманием пользователя, акцентировать более важные элементы и убирать на 2й план второстепенные  
~Типы баланса:~  

1. симметричный - одинаковый вес относительно оси. Формальный, изящный, формальный. Предсказуем, очевиден, статичен  
    Пример: интернет-магазины, блоги  
    
2. ассиметричный - баланс достигается за счет выделения более значимой части с помощью размера, цвета или расположения. Динамичный, энергичный, интересный.  
    Пример: разные сайты, наиболее используемый  
    
3. мозаичный - множество элементов с одинаковой значимостью сбалансированы в пространстве, но создают ощущение хаоса.  
    Пример: Новостные сайты. ozon  
    
4. радиальный - все элементы распологаются относительно центральнйо точки. Легко удерживать внимание на точке. Элементы выстраиваются вокруг нее.  
    Пример: экраны выбора в играх  
    ~Достижение баланса:~  
    

- форма - негеометричные формы привлекают
- размер - больший размер привлекает
- цвет - яркий привлекает
- оттенок - более темные оттенки перевешивают
- текстура - с текстурой перевешивают
- расположение относительно края и центра
- плотность - более плотно расположенные перевешивают
- объем - более объемные привлекают
- ориентация -вертикальные тяжелее горизонтальных, диагональные самые тяжелые

**IV Белое пространство**  
-это пространство между элменетами, любое которое не занятое контентом. Негативное, воздух, контрформа.  
Зачем? Улучшается восприятие контента, читаемости, не перегружается инфой. Самый противоречивый принцип  
Количество белого пространства зависит от цели и количества контента  
~Подходы для управления белым пространством:~  

1. Добавить воздуха
2. Сначала сделать слишком много воздуха и потом уменьшать, чтобы было читаемо
3. Используем блоки с определенной кратностью, отталкиваемся от размера контейнера-экрана или телефона с отступами. Используем определенную размерную сетку(обычно кратностью 4-8px). Эти размеры определяются не только кратностью, но и соотношением этих размеров друг с другом. Во сколько раз одно больше другого
4. Смотрим глазами пользователя: ставим блюр на дизайн и анализируем, читаются ли блоки, куда идет фокус

**V Принципы выравнивания**  
~относительно сторон~  

- по левой стороне-легкочитаемое
- по правой-трудно
- по верху
- по низу  
    ~относительно центра~  
    -когда хотим сфокусировать взгляд пользователя. Как правило при центральном выравнивании в каждом элементе по 1-2 строки, иначе ухудшается читаемость. Заголовок-описание-призыв к действию  
    
- по вертикали
- по горизонтали - для заголовков
- по ширине - в вебе не используется, только в печати. Делаем колонки с текстом, если уменьшаем расстояние, то воспринимается как единый текст, иначе как газетная верстка. Создает реки и белые дыры.  
    Текст всегда выравнивается отностельно текста, а не относительно картинки. Взгляду всегда проще идти по прямым линиям а не извилистым.
