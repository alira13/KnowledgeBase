### Инициализация
По умолчанию
Все переменные должны быть обязательно проинициализированы. Если они являются полями, то непроинициализированная даже не скомпилируется. Если переменная внутри метода, то при первом обращении к непроинициализированной также будет ошибка компиляции.То есть у переменных нет значений по умолчанию как у Java.

| **Тип инициализации**             | **Описание**                                                   | **Этап присваивания**                                                                                           | **Пример**                     |
| --------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| **Прямая инициализация**          | Переменная инициализируется сразу при объявлении.              | **Компиляция**: Значение присваивается при компиляции, так как оно известно на этапе компиляции.                | `val name = "John"`            |
| **Инициализация по умолчанию**    | Такой нет                                                      |                                                                                                                 |                                |
| **Инициализация через выражение** | Переменная инициализируется значением, вычисленным выражением. | **Компиляция**: Если выражение известно на этапе компиляции, то оно вычисляется в момент компиляции.            | `val result = 10 + 20`         |
| **Через конструктор**             | Инициализация переменной через конструктор класса.             | **Компиляция**: Присваивание значений происходит в момент создания объекта, который выполняется при компиляции. | class Person(val name: String) |
