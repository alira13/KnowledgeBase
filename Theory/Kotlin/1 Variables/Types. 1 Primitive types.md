### Циклическое переполнение
В Kotlin, как и в других языках программирования, циклическое переполнение может возникать при работе с целочисленными типами данных, когда значение превышает максимально допустимое для этого типа и "переполняется" в минимальное значение. Это может произойти с типами `Byte`, `Short`, `Int`, `Long`, а также с их беззнаковыми аналогами `UByte`, `UShort`, `UInt`, `ULong`.
### Значения по умолчанию
#### Kotlin
В Kotlin нет встроенной поддержки значений по умолчанию для переменных

### Java
В Java значения по умолчанию присваиваются переменным в зависимости от их типа данных. Эти значения автоматически присваиваются переменным при их объявлении, если явное значение не указано. Вот основные значения по умолчанию для различных типов данных в Java:
- **Числовые типы** (`byte`, `short`, `int`, `long`, `float`, `double`): Значение по умолчанию равно **0**[1](https://dzen.ru/a/ZZWBdh87oE4Wr8Zk)[3](https://dzen.ru/a/ZRvIiDTbkSq1aFn7)[9](https://proglang.su/java/variable-types).
- **Логический тип** (`boolean`): Значение по умолчанию равно **false**[1](https://dzen.ru/a/ZZWBdh87oE4Wr8Zk)[3](https://dzen.ru/a/ZRvIiDTbkSq1aFn7)[9](https://proglang.su/java/variable-types).
- **Символьный тип** (`char`): Значение по умолчанию равно **'\u0000'** (нулевой символ)[1](https://dzen.ru/a/ZZWBdh87oE4Wr8Zk)[3](https://dzen.ru/a/ZRvIiDTbkSq1aFn7).
- **Ссылочные типы** (классы, интерфейсы, массивы): Значение по умолчанию равно **null**[1](https://dzen.ru/a/ZZWBdh87oE4Wr8Zk)[3](https://dzen.ru/a/ZRvIiDTbkSq1aFn7)[9](https://proglang.su/java/variable-types).

Эти значения по умолчанию применяются для переменных экземпляра и статических переменных. Однако локальные переменные в Java не имеют значений по умолчанию и должны быть инициализированы перед использованием, чтобы избежать ошибок компиляции[7](https://ru.stackoverflow.com/questions/1102073/%D0%9F%D0%BE%D1%87%D0%B5%D0%BC%D1%83-%D0%BB%D0%BE%D0%BA%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5-%D0%BF%D0%B5%D1%80%D0%B5%D0%BC%D0%B5%D0%BD%D0%BD%D1%8B%D0%B5-%D0%BD%D0%B5-%D0%BC%D0%BE%D0%B3%D1%83%D1%82-%D0%B8%D0%BC%D0%B5%D1%82%D1%8C-%D0%B7%D0%BD%D0%B0%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-%D0%BF%D0%BE-%D1%83%D0%BC%D0%BE%D0%BB%D1%87%D0%B0%D0%BD%D0%B8%D1%8E).

### uShort, uLong  - беззнаковые типы
В Kotlin также есть беззнаковые типы и тд. Соответствнно их верхний диапазон в 2 раза больше знакового. 
Достаточно экзотические штуки, которые при жуткой необходимости стоит использовать. Так как Java не имеет прямых аналогов беззнаковых типов. Декомпилируется UInt->int. Это означает, что для работы с беззнаковыми типами в Java необходимо использовать особые подходы.
```kotlin
var num: UInt = 0u
```

### Char - cимвольный тип данных
Каждому символу соответствует числовой код. Таблица соответсвия ASCII. Поэтому можно применять оператор инкремент и дикремент, работать как с int
```kotlin
// распечатать алфавит Способ 1
 var letter:Char = 'a'
    do {
        println(letter++)
    }
    while(letter<='z')

// распечатать алфавит Способ 2
for (i in 'a'..'z'){
        println(i)
    }
    
// преобразовать строку в массив char
val passward = readln().toCharArray()
```
