Допускающие значение null и нет
 - nullable
 - non nulable

null - это когда ссылка не указывает ни на какой объект. Объекта нет. Ссылка на стол есть, а самого стола нет.
`val table:Table?=null`

В зависимости от самого типа
- примитивные
- коллекции
- Any, Unit, Nothing
- функции как типы данных
- классы и объекты

| **Характеристика**        | **Non-null типы**                                                                  | **Nullable типы**                                                                       |
| ------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **Ключевое слово**        | Без `?`                                                                            | С `?`                                                                                   |
| **Может быть `null`?**    | Нет                                                                                | Да                                                                                      |
| **Пример в Kotlin**       | `val name: String = "Kotlin"`                                                      | `val name: String? = null`                                                              |
| **Пример в Java**         | `String name = "Kotlin"`                                                           | `String name = null`                                                                    |
| **Типы данных**           | `String`, `Int`, `Boolean`, `Char`, `Float`, `Double`, `Long`, `Byte`, `Short`     | `String?`, `Int?`, `Boolean?`, `Char?`, `Float?`, `Double?`, `Long?`, `Byte?`, `Short?` |
| **Как использовать**      | Переменная не может быть `null`. Просто инициализируется значением                 | Переменная может быть `null`, нужна проверка на null                                    |
| **Пример использования**  | `val name: String = "Kotlin"`                                                      | `val name: String? = null; if (name != null) { println(name.length) }`                  |
| **Преобразования в Java** | Соответствует обычным примитивам и объектам (например, `String`, `int`, `boolean`) | Соответствует оберточным классам Java (`Integer`, `Boolean`, `String`)                  |
| **Основные особенности**  | Безопасность от ошибок `NullPointerException`, гарантированное значение            | Нужно проверять на `null` перед использованием, чтобы избежать ошибок                   |

Безопасный вызов+функция

| **`let` с безопасным вызовом** |     | `name?.let { println(it.length) }`                      | Выполнение кода только, если объект не равен `null`. Let возвращает значение             |
| ------------------------------ | --- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **`run` с безопасным вызовом** |     | `name?.run { println("Length: $length") }`              | Выполнение действий внутри блока, если объект не равен `null`. Run ничего не возвращает. |
| **`takeIf`**                   |     | `val validName = name?.takeIf { it.length > 3 }`        | Возвращает значение, если выполняется условие, или `null`.                               |
| **`takeUnless`**               |     | `val invalidName = name?.takeUnless { it.length > 10 }` | Возвращает значение, если условие не выполняется, или `null`.                            |

### Тип не определен
Когда мы вызываем код из Java, то там нет понятия null и not null и компилятор не может вывести тип и обычно пишет допустим String!
Это значит что нам явно самим надо выбрать тип, String или String?
`Thread.currentThread.name`
