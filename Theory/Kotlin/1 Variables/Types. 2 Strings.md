### **Основные свойства String**

String в kotlin - это неизменяемый (immutable) объект. Любые изменения содержимого строки создают новый объект. Ссылку на строку можно менять (var val). Ссылка на строку хранится в стеке, а содержимое в куче.

1. **Неизменяемость (Immutable):**
    - Объекты `String` в Kotlin неизменяемы, что означает, что после создания строка не может быть изменена.
    - Любая операция, которая "изменяет" строку, создает новый объект.
2. **Интернационализация:**
    - Поддерживает работу с символами Unicode, что позволяет работать с текстами на разных языках.

## Что делает `joinToString()`?

- **Объединяет элементы**: Преобразует все элементы коллекции в строку, используя заданный разделитель.
- **Использует префикс и постфикс**: Позволяет добавлять строку перед первым элементом (`prefix`) и после последнего элемента (`postfix`).
- **Ограничивает количество элементов**: Может ограничивать количество элементов, включаемых в результирующую строку (`limit`), и добавлять специальную строку (`truncated`), если элементов больше лимита.
- **Преобразует элементы**: Позволяет кастомизировать представление каждого элемента с помощью функции `transform`.
```kotlin
`val numbers = listOf(1, 2, 3, 4, 5) 
println(numbers.joinToString(     
	separator = " + ", // Разделитель между элементами    
	prefix = "=", // Префикс перед первым элементом    
	postfix = " result" // Постфикс после последнего элемента 
)) 
// Вывод: =1 + 2 + 3 + 4 + 5 result`
```
### String vs StringBuilder
StringBuilder - объект, который позволяет формировать строку из других строк
При модификации например добавлении слов в строку каждый раз создается новый объект с добавленным словом, а старый остается. Это засоряет оперативную память. Сборщик мусора в какой-то момент приходит и начинает очищать, что существенно замедляет работу программы. Поэтому нужен mutable - объект, который мы бы могли изменять.
```kotlin
//создаем StringBuilder
val result = StringBuilder()
// модифицируем строку как SB
        for (line in lines) {
            result.append(line) 
            result.append("\n")
        }
// конвертируем обратно в строку
        return result.toString()
```

Это означает, что использование такого кода или объекта не приведет к непредсказуемому поведению или ошибкам, даже если несколько потоков выполняются параллельно.
## **Как работает `StringBuilder`?**

`StringBuilder` в Kotlin, как и в Java, является изменяемым классом, используемым для эффективного построения строк. Он работает по принципу буфера, что позволяет избежать создания множества временных объектов при конкатенации строк.

## Как работает `StringBuilder` под капотом

1. **Инициализация буфера**: При создании экземпляра `StringBuilder` в памяти резервируется определенная емкость (по умолчанию 16 символов). Если вы передаете строку в конструктор, емкость будет равна длине этой строки плюс 16 символов[1](https://metanit.com/java/tutorial/7.3.php)[5](https://metanit.com/sharp/tutorial/7.3.php).
    
2. **Добавление строк**: Когда вы используете методы `append()` или `insert()`, `StringBuilder` проверяет, хватает ли текущей емкости для добавления новых символов. Если емкости достаточно, символы добавляются в конец или вставляются по указанному индексу. Если емкости не хватает, `StringBuilder` удваивает свою емкость, создает новый буфер и копирует в него все существующие символы, а затем добавляет новые[3](https://habr.com/ru/articles/172689/)[5](https://metanit.com/sharp/tutorial/7.3.php).
    
3. **Управление памятью**: Чтобы повысить производительность, `StringBuilder` позволяет явно задавать емкость с помощью метода `ensureCapacity()`. Это уменьшает количество перераспределений памяти при добавлении большого количества символов[1](https://metanit.com/java/tutorial/7.3.php)[5](https://metanit.com/sharp/tutorial/7.3.php).
    
4. **Получение строки**: Когда вы закончили добавлять символы, вы можете получить результирующую строку с помощью метода `toString()`. Этот метод возвращает копию строки, хранящейся в буфере[1](https://metanit.com/java/tutorial/7.3.php).

### **Основные принципы работы `StringBuilder`**

1. **Внутренний буфер**: `StringBuilder` использует **массив символов (`CharArray`)**, который увеличивается при необходимости.
2. **Автоматическое увеличение размера**: Если буфер заполнен, выделяется новый массив **с большим размером**, а старые данные копируются.
3. **Изменяемая структура**: Операции добавления (`append`), вставки (`insert`), удаления (`delete`) и изменения (`setCharAt`) происходят **без создания новых объектов**.
