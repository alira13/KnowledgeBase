 - Последовательная обработка элементов. Можем их последовательно обрабатывать(фильтровать)
 - Прекращение работы с элементами, когда они больше не требуются. Можем закрыть кран, когда набралось достаточно отфильтрованных капелек

В Kotlin списки и потоки данных (или последовательности) имеют существенные различия в использовании и применении. Ниже приведена таблица, сравнивающая списки и последовательности в Kotlin:

|**Характеристика**|**Списки (List)**|**Последовательности (Sequence)**|
|---|---|---|
|**Реализация**|Реализованы как коллекции, которые хранят данные в памяти.|Реализованы как ленивые коллекции, которые вычисляют данные по мере необходимости.|
|**Память**|Занимают фиксированное место в памяти, так как все элементы хранятся сразу.|Занимают меньше памяти, так как элементы вычисляются и обрабатываются по одному.|
|**Операции**|Поддерживают все операции сразу, создавая промежуточные коллекции.|Выполняют операции лениво, без создания промежуточных коллекций.|
|**Эффективность**|Менее эффективны для больших наборов данных и сложных операций.|Более эффективны для больших наборов данных и сложных операций.|
|**Примеры методов**|`map()`, `filter()`, `fold()`|`map()`, `filter()`, `fold()` (выполняются лениво)|
|**Применение**|Используются для небольших наборов данных или когда необходимо сохранить порядок.|Используются для больших наборов данных или когда важна экономия памяти.|

В отличие от Java, где потоки (streams) явно преобразуются между коллекциями и потоками, в Kotlin списки и последовательности можно использовать более гибко, без явного преобразования между ними[7](https://dzen.ru/a/ZgLmks7pNhhxhF3T)[9](https://metanit.com/kotlin/tutorial/7.6.php).

### Создание потоков


| **Способ создания**      | **Описание**                                                            | **Пример**                                                                                        | **Плюсы**                                                                             | **Минусы**                                                                  |
| ------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| **`sequenceOf()`**       | Создание последовательности из набора элементов.                        | `val numbersSequence = sequenceOf("four", "three", "two", "one")`                                 | Простота использования, быстрое создание для небольших наборов данных.                | Ограниченность в размере набора данных.                                     |
| **`asSequence()`**       | Преобразование `Iterable` в последовательность.                         | `val numbers = listOf("one", "two", "three", "four"); val numbersSequence = numbers.asSequence()` | Экономия памяти, ленивая обработка.                                                   | Может быть медленнее для небольших наборов данных из-за накладных расходов. |
| **`generateSequence()`** | Создание последовательности на основе функции, генерирующей элементы.   | `val oddNumbers = generateSequence(1) { it + 2 }; println(oddNumbers.take(5).toList())`           | Возможность создания бесконечных последовательностей, гибкость в генерации элементов. | Может быть сложно управлять бесконечными последовательностями.              |
| **`sequence()`**         | Создание последовательности с помощью функций `yield()` и `yieldAll()`. | `val numbers = sequence { yield(1); yield(4); yield(7) }; println(numbers.joinToString())`        | Гибкость в создании элементов, возможность использования для сложных генераций.       | Может быть сложнее в использовании для простых случаев.                     |

yield - restricted suspend, можно только для последовательностей использовать
Функция `yield()` в Kotlin используется для создания последовательностей (`Sequence`) с помощью функции `sequence()`. Она позволяет генерировать элементы последовательности по одному, возвращая их потребителю и приостанавливая выполнение до тех пор, пока не будет запрошен следующий элемент.

- **Возвращает значение**: `yield()` принимает один элемент и возвращает его потребителю последовательности.
- **Приостанавливает выполнение**: После возвращения элемента, функция приостанавливает выполнение до тех пор, пока не будет запрошен следующий элемент.
- **Используется в `sequence()`**: `yield()` обычно используется внутри функции `sequence()`, которая позволяет создавать элементы последовательности лениво.

- `yieldAll()` может принимать `Iterable`, `Iterator` или другую `Sequence`, позволяя добавлять несколько элементов одновременно.
- `yield()` используется для добавления одного элемента за раз.
