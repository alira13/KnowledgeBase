Все состояния экрана хранятся в одной переменной flow и когда изменяется это состояние, мы просто его эмитим в эту переменную.
В другой переменной также flow мы подписываемся на state flow и перерисовываем ui экрана в зависимости от state

Нам нужны параметры
 - BufferOverflow.DROP_OLDEST - выкидывать все старые и не учитывать их. Хотим сразу актуальное состояние
 - показывать новому подписчику только последний эмит
 - доп размер буфера не нужен
 - дублирование эмитов не нужно
 - и обязательно нужно класть какой-то объект в конструктор(начальное состояние)

MutableStateFlow = MutableSharedFlow с этими параметрами


StateFlow
```kotlin
private val sharedFlow = MutableSharedFlow<Int>(  
    replay = 1, // количество элементов для новых subscribers  
    extraBufferCapacity = 0, // то есть в буфере всегда будет хранится только 1 значение из replay  
    onBufferOverflow = BufferOverflow.DROP_OLDEST // только последнее актуальное будет collect, все остальные значения будут игнорироваться  
)
//+ не может быть повторяющихся элементов
```

Абсолютно всегда имеет какое-то значение                       |

| **Подписчики**                      | replay                                                                                               | Можно менять. Всегда 0                                                            |

| **Использование**                   |                                                                                                      | Для обмена событиями между компонентами                                                                                                                                                    | Для управления состоянием приложения                                                                  |
