Классы value представляют собой оболочки для какого-то значения.
Например мы используем разные id в приложении и чтобы случайно не передать другой id типа Int мы можем использовать вместо Int value class PersonId(val value:Int). И для передачи id уже будем использовать этот тип

Под капотом не создается объект, а лишь вызывается статический метод-конструктор в который передается значение.

## Value Классы в Kotlin

**Value Классы** в Kotlin — это специальный тип классов, которые позволяют создавать обертки вокруг одного значения, обеспечивая семантическую безопасность типов без дополнительных накладных расходов на выполнение. Они объявляются с помощью ключевого слова `value` и могут быть использованы для создания новых типов, которые не совместимы с их базовым типом по назначению.

## Основные характеристики Value Классов:

- **Одно свойство**: Value Классы могут иметь только одно свойство в конструкторе.
    
- **Эффективность**: При выполнении Value Классы не создают дополнительных объектов, что делает их эффективными для использования с большим количеством объектов.
    
- **Типовая безопасность**: Они обеспечивают типовую безопасность, предотвращая случайное использование базового типа в контексте Value Класса.
    
- **Поддержка функций и интерфейсов**: Value Классы могут содержать функции и реализовывать интерфейсы, что делает их гибкими для использования в различных сценариях.
    

## Пример Value Класса:

kotlin

`value class Password(private val s: String)`

## Inline Классы

Value Классы часто путают с **Inline Классами**, которые представляют собой улучшенную версию Value Классов. Inline Классы помечаются аннотацией `@JvmInline` и также представляют собой обертки вокруг одного значения, но они полностью инлайнятся в места использования, что делает их еще более эффективными.

kotlin

`@JvmInline value class Name(private val s: String)`

## Data Классы в Kotlin

**Data Классы** — это классы, предназначенные для хранения данных. Они объявляются с помощью ключевого слова `data` и автоматически генерируют методы для сравнения, копирования и вывода объектов.

## Основные характеристики Data Классов:

- **Множество свойств**: Data Классы могут иметь несколько свойств в конструкторе.
    
- **Автоматические методы**: Компилятор автоматически генерирует методы `equals()`, `hashCode()`, `toString()` и `copy()`.
    
- **Равенство по значению**: Data Классы используют равенство по значению, а не по ссылке.
    
- **Гибкость**: Data Классы могут иметь несколько конструкторов и поддерживают наследование.
    

## Пример Data Класса:

kotlin

`data class User(val name: String, val email: String)`

## Сравнение Value Классов и Data Классов

|**Характеристика**|**Value Классы**|**Data Классы**|
|---|---|---|
|**Количество свойств**|Только одно|Множество|
|**Автоматические методы**|Нет|Да (`equals()`, `hashCode()`, `toString()`, `copy()`)|
|**Типовая безопасность**|Да, через семантику|Да, через равенство по значению|
|**Эффективность**|Высокая, без дополнительных объектов|Зависит от количества объектов|
|**Гибкость**|Поддерживают функции и интерфейсы|Поддерживают наследование и несколько конструкторов|

## Когда использовать каждый тип классов:

- **Value Классы**: Используйте, когда нужно создать новый тип с одним значением, обеспечивая типовую безопасность без накладных расходов.
    
- **Data Классы**: Используйте, когда нужно хранить несколько значений и автоматически генерировать методы для сравнения и копирования.
    

В итоге, Value Классы и Data Классы служат разным целям в Kotlin. Value Классы идеальны для создания оберток вокруг одного значения с высокой эффективностью, в то время как Data Классы лучше подходят для хранения нескольких значений и обеспечения автоматических методов для работы с этими данными.
