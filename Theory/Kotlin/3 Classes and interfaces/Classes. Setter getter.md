Setter - функция, которая устанавливает значение приватной переменной.
Getter - функция, которая считывает значение приватной переменной.

- В kotlin при создании ПУБЛИЧНОЙ переменной в конструкторе или просто в классе на самом деле создается приватная и ее сеттер и геттер
- Если мы хотим, чтобы геттеры и сеттеры не создавались, нам нужно сделать поле приватным
- Поэтому если мы сделаем переменную публичной и определим setParam и getParam, компилятор выдаст ошибку так как он уже создал эти методы за нас.
- Если переменная val, то для нее автоматически создается только getter. У изменяемых переменных var автоматически создается и getter и setter, поэтому их оба можем перепределить
- Доступ к приватному полю осуществляется через field. Аргумент, который присваиваем полю может иметь любое имя
- Если нам нужно устанавливать какое-то значение только внутри класса, можем сделать setter-private
```kotlin
var age: Int = 0  
    set(value) {  
        if (value < field) {  
            println("Мы не молодеем. Новое значение возвраста $value должно быть больше текущего $field")  
        } else field = value  
    }  
    get() {  
        println("Спрашивать возраст неприлично")  
        return field  
    }
```

Функции
 - когда при установке или получении значений нужны какие-то доп действия или проверки
 - если какое-то свойство зависит от других свойств, то каждый раз изменяя исходное свойство, нужно пересчитывать и зависимое свойство, то есть нужно будет переопределить getter зависимого 
```kotlin
 class Rectangle(var width: Int, var height: Int) {  
    val area: Int  
        get() {  
            return width * height  
        }  
}
```

### Отличие присвоения от getter
```kotlin
//переменная для внутренней модификации - backing field
	private val _someList:MutableList = loadList()
	// переменная наружу. !
	// toList() возвращает новый объект в обоих случаях. Но getter позволяет каждый раз вызывать toList() при чтении someList, а при присваивании мы только 1 раз вызовем toList()
	// !!! Каждый раз при обращении к somList мы обновляем его значения и возвращаем актуальный _someList, преобразованный в неизменяемый list
	val someList
		get() =  _someList.toList()

//  Здесь мы один раз взяли список, преобразовали его в неизменяемый и при изенении _someList значение someList не будет меняться
	val someList = _someList.toList()
```
