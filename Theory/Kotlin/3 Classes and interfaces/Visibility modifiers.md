
| **Модификатор доступа Kotlin**                       | **Описание**                                                          | **Где используется**                                                                                                                 | **Пример Kotlin**                         | **Аналог в Java**                                            | **Пример Java**                       |
| ---------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------- | ------------------------------------------------------------ | ------------------------------------- |
| **`public`**<br>по умолчанию, если не указан другой. | По умолчанию, видимость везде в проекте.                              | доступен из любого места в проекте.                                                                                                  | `public val name: String = "John"`        | `public`                                                     | `public String name = "John";`        |
| **`internal`**                                       | Видимость только в пределах модуля (например, внутри одного проекта). | элемент должен быть доступен только внутри модуля.                                                                                   | `internal class MyClass`                  | **Нет прямого аналога**, но после декомпиляции станет public | `public class MyClass`                |
| **`protected`**                                      | Видимость внутри класса и его подклассов (для наследников).           | доступен только в классе и его подклассах, **а также в том же типе(когда одному классу передают такой же тип как и он сам)**         | `protected fun calculateSalary()`         | `protected`                                                  | `protected void calculateSalary()`    |
| **`private`**                                        | Видимость только внутри класса или объекта.                           | только внутри самого класса, объекта или файла.<br>**а также в том же типе(когда одному классу передают такой же тип как и он сам)** | `private var password: String = "secret"` | `private`                                                    | `private String password = "secret";` |

По умолчанию, если не указан модификатор доступа:
 - в Kotlin - public
 - в Java - default (элемент доступен только внутри того пакета, в котором он был объявлен. Этот модификатор не указывается явно, если не используется другой модификатор доступа)
