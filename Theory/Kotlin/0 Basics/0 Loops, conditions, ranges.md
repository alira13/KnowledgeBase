### Условия
Условия If и when - это выражения, которые возвращают значения. Если в теле when много строк, последняя операция будет возвращаемым значением.
```kotlin
	val mass = readln().toInt()
    val price = when(mass){
        in 0..<2 -> 150
        in 2..<5 -> 200
        in 5..<12 -> 250
        in 12..<18 ->300
        in 18..<30 -> 350
        in 30..<200-> 1000
        else -> 0
    }
```

### Циклы 
- не возвращают значения

| **Цикл**              | **Описание**                                                                                                                                           | **Синтаксис**                                      | **Пример**                                                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`for`**             | Перебор элементов коллекции, диапазона или другого итерируемого объекта.                                                                               | `for (element in collection) { /* действия */ }`   | `kotlin<br>for (i in 1..5) { println(i) } // Вывод: 1, 2, 3, 4, 5`                                                                                  |
| **`while`**           | Выполняется, пока условие истинно.                                                                                                                     | `while (condition) { /* действия */ }`             | `kotlin<br>var i = 1<br>while (i <= 3) { println(i); i++ } // Вывод: 1, 2, 3`                                                                       |
| **`do-while`**        | Выполняет действия хотя бы один раз, а затем проверяет условие.                                                                                        | `do { /* действия */ } while (condition)`          | `kotlin<br>var i = 1<br>do { println(i); i++ } while (i <= 3) // Вывод: 1, 2, 3`                                                                    |
| **`repeat`**          | Выполняет заданное количество повторений.                                                                                                              | `repeat(times) { /* действия */ }`                 | `kotlin<br>repeat(3) { println("Hello!") } // Вывод: Hello! Hello! Hello!`                                                                          |
| **`break`**           | Прерывает выполнение текущего цикла полностью.                                                                                                         | Внутри цикла: `if (condition) break`               | `kotlin<br>for (i in 1..5) { if (i == 3) break; println(i) } // Вывод: 1, 2`                                                                        |
| **`continue`**        | Пропускает текущую итерацию и переходит к следующей.                                                                                                   | Внутри цикла: `if (condition) continue`            | `kotlin<br>for (i in 1..5) { if (i == 3) continue; println(i) } // Вывод: 1, 2, 4, 5`                                                               |
| **Именованные метки** | Используются для управления вложенными циклами. Установка имени для цикла чтобы потом по имени можно было задетектить имя цикла и выйти именно из него | Метка: `label@` и `break@label` / `continue@label` | `kotlin<br>outer@ for (i in 1..3) { for (j in 1..3) { if (i == 2 && j == 2) break@outer; println("i=$i, j=$j") } } // Вывод: i=1,j=1..j=3; i=2,j=1` |

### Диапазоны

| **Вид диапазона**                      | **Описание**                                                                                | **Пример**                                                           | **Вывод**      |
| -------------------------------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | -------------- |
| **От начала до конца (`..`)**          | Перебор всех значений от начала до конца включительно.<br>val a=0..100(0, 1..100)           | `kotlin<br>for (i in 1..5) { println(i) }`                           | 1, 2, 3, 4, 5  |
| **До конца, исключая конец (`until`)** | Перебор значений от начала до конца, конец не включается.\|<br>val a=0 until 100 (0, 1..99) | `kotlin<br>for (i in 1 until 5) { println(i) }`                      | 1, 2, 3, 4     |
| **Обратный диапазон (`downTo`)**       | Перебор значений в обратном порядке.                                                        | `kotlin<br>for (i in 5 downTo 1) { println(i) }`                     | 5, 4, 3, 2, 1  |
| **С шагом (`step`)**                   | Перебор значений с указанным шагом.                                                         | `kotlin<br>for (i in 1..10 step 2) { println(i) }`                   | 1, 3, 5, 7, 9  |
| **Диапазон символов**                  | Перебор букв алфавита.                                                                      | `kotlin<br>for (c in 'a'..'e') { println(c) }`                       | a, b, c, d, e  |
| **Диапазон с фильтрацией**             | Перебор с применением фильтра.                                                              | `kotlin<br>for (i in (1..10).filter { it % 2 == 0 }) { println(i) }` | 2, 4, 6, 8, 10 |
| **Проверка вхождения в диапазон**      | Проверка, находится ли число в диапазоне                                                    | val time = 7<br>val isMorning = time in 6..<12                       | isMorning=true |
