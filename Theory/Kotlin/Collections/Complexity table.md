Вот таблица временной сложности операций для различных структур данных в Kotlin:

|**Структура данных**|**Операция**|**Сложность**|**Обоснование**|
|---|---|---|---|
|**ArrayList**|Доступ по индексу|O(1)|Прямой доступ к элементу|
||Добавление (в конец)|O(1)*|Амортизированная константа|
||Удаление|O(n)|Сдвиг элементов|
||`contains()`|O(n)|Линейный поиск|
|**LinkedList**|Доступ по индексу|O(n)|Последовательный перебор|
||Добавление (в начало/конец)|O(1)|Изменение ссылок соседних узлов|
||Удаление (из начала/конца)|O(1)|Аналогично добавлению|
||`contains()`|O(n)|Линейный поиск по узлам|
|**HashSet**|Добавление (лучший случай)|O(1)|Хэширование без коллизий|
||Удаление (лучший случай)|O(1)|Прямой доступ по хэшу|
||`contains()` (лучший случай)|O(1)|Проверка наличия в бакете|
|**TreeSet**|Добавление|O(log n)|Балансировка красно-чёрного дерева|
||Удаление|O(log n)|Поиск + балансировка|
||`contains()`|O(log n)|Двоичный поиск в дереве|
|**HashMap**|`containsKey()` (лучший случай)|O(1)|Прямой доступ по хэшу|
||Добавление (лучший случай)|O(1)|Вставка в бакет|
||Удаление (лучший случай)|O(1)|Удаление из бакета|
||`containsValue()`|O(n)|Перебор всех значений|
|**TreeMap**|`containsKey()`|O(log n)|Поиск в дереве|
||Добавление|O(log n)|Вставка + балансировка|
||Удаление|O(log n)|Поиск + балансировка|
||`containsValue()`|O(n)|Полный обход дерева|

**Примечания:**

- (*) Для `ArrayList.add()` амортизированная сложность O(1), но при расширении массива временно O(n)
    
- Худший случай для HashSet-операций: O(n) при коллизиях
