Kotlin не делает автоматическое приведение типов при вызове перегруженного метода, поэтому возникает ошибка компиляции.


Анонимная функция(лямбда-выражение) - функция без имени

 - Для описания лямбды нужны указать сигнатуру метода, т.е набор входных и выходных параметров. Входные описываются в круглых скобках. Выходные после стрелки
 - При описании тела лямбды последняя строка-возвращаемое значение
 - Если лямбда принимает только один параметр, его можно не указывать. Компилятор его заменит на it
 - Если последний аргумент в методе это лямбда, ее можно вынести за круглые скобки и описать в фигурных
```kotlin
fun main() {  
    val lambda1: (String) -> Unit = {  
        val a = 1  
        println(it + a.toString())  
    }  
  
    val lambda2: (String) -> Int = { someText ->  
        val a = 2  
        println(someText + a.toString())  
        a  
    }  
  
    lambda1("Hello")  
    val a = lambda2("Buy")  
    println(a)  
  
    // описываем лямбду за круглыми скобками в фигурных  
    filter("Hi") {  
        println(it)  
    }  
}  
  
// функция, которая вызывает другую функцию  
fun filter(item: String, lambda: (String) -> Unit) {  
    lambda(item)  
}
```




В Kotlin **нелокальный return** — это выход из функции, охватывающей текущую лямбду, а не только из самой лямбды. Это работает благодаря метке (`@label`), указывающей, откуда нужно выйти.  

### Как это работает:
Обычно в лямбдах `return` действует локально, т.е. просто завершает выполнение самой лямбды. Однако, если использовать `return@label`, можно прервать выполнение внешней функции.

### Пример локального return:
```kotlin
fun main() {
    listOf(1, 2, 3).forEach {
        if (it == 2) return // ОШИБКА: return пытается выйти из main()
        println(it)
    }
    println("Это сообщение не будет напечатано")
}
```
Этот код **не скомпилируется**, потому что `return` пытается выйти из `main()`, а не только из `forEach`.

### Использование нелокального return:
Чтобы выйти только из `forEach`, нужно явно указать метку:
```kotlin
fun main() {
    listOf(1, 2, 3).forEach label@{
        if (it == 2) return@label // Выход только из лямбды
        println(it)
    }
    println("Программа продолжает выполняться")
}
```
Здесь `return@label` выходит **только из лямбды**, а программа продолжает выполняться.

### Нелокальный return в `inline` функциях
Однако, если функция `inline`, `return` может выйти из внешней функции:
```kotlin
inline fun test() {
    listOf(1, 2, 3).forEach {
        if (it == 2) return // Нелокальный return: выход из test()
        println(it)
    }
    println("Это не выполнится")
}

fun main() {
    test()
    println("Программа продолжает выполняться")
}
```
Здесь `return` прерывает `test()`, но `main()` продолжает выполнение.

### Итог:
- **Локальный return (`return@label`)** → прерывает только лямбду.
- **Нелокальный return (`return` в `inline` функциях)** → прерывает всю функцию, содержащую лямбду.

Использование `return@label` помогает избежать ошибок и сделать код более понятным. 🚀
