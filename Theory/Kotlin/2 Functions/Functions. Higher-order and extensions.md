Когда нужно добавить какие-то новые методы в класс, который не является нашим, внутрь которого мы не можем добавить методы. Он закрыт.
Тогда мы можем использовать функции расширения. И эта функция будет такая же по синтаксису, как будто мы ее создаем внутри нужного нам класса.
Доступ к приватным полям? Экстеншены никак не влияют никак на исходный класс, поэтому им доступны только к публичным полям.
По факту функция расширения преобразуется в функцию с параметром и работает как обычная функция. Поэтому если есть функция с таким же названием и сигнатурой, то возникнет ошибка компиляции.

### Функции высшего порядка
Функция высшего порядка-функция, которая на вход принимает другую функцию или возвращает другую функцию.

Стандартные функции-расширения высшего порядка:
 - filter{}
 - sortedBy{}
 - forEach{}

## **Функции расширения (`Extension Functions`) в Kotlin** 🚀

 - стандартные(популярные, уже созданы за нас)
 - пользовательские(можно создать самом)
 
Функции расширения – это мощная особенность **Kotlin**, которая позволяет **добавлять новые функции к существующим классам** (включая стандартные и сторонние классы) **без изменения их кода**.

---

## **1️⃣ Как работают функции расширения?**

Функция расширения **по сути является обычной функцией**, но она вызывается как будто это метод класса.

### **Пример: добавим метод `isEven()` для `Int`**

```kotlin
fun Int.isEven(): Boolean {
    return this % 2 == 0
}

fun main() {
    println(4.isEven()) // true
    println(7.isEven()) // false
}
```

🔹 **Ключевые моменты:**

- `Int` – это **тип, который расширяется**.
- `isEven()` – это **новая функция** для `Int`.
- `this` – это текущий объект (`Int`), к которому применяется функция.

---

## **2️⃣ Особенности и ограничения функций расширения**

### ✅ **Плюсы**:

✔ Позволяют **расширять функциональность классов** без наследования.  
✔ Работают с **любыми классами** (включая `String`, `List`, `View` и другие).  
✔ Упрощают код и делают его **более читаемым**.

### ❌ **Ограничения**:

1. **Не изменяют оригинальный класс** – это просто синтаксический сахар.
2. **Могут быть переопределены, но не виртуальны**:
    - Если у класса есть метод с таким же именем, он **будет вызван вместо расширения**.
    - Расширение **не переопределяет** методы.

🔹 **Пример с переопределением**:

```kotlin
open class A {
    open fun hello() = "Hello from A"
}

fun A.hello() = "Hello from extension"

fun main() {
    val a = A()
    println(a.hello()) // "Hello from A", а не "Hello from extension"
}
```

## **3️⃣ Функции расширения для стандартных классов**

### **🔹 Расширение `String`:**

```kotlin
fun String.firstChar(): Char {
    return this[0]
}

fun main() {
    println("Kotlin".firstChar()) // 'K'
}
```

### **🔹 Расширение `List<T>`:**

```kotlin
fun <T> List<T>.secondOrNull(): T? {
    return if (this.size >= 2) this[1] else null
}

fun main() {
    val list = listOf(1, 2, 3)
    println(list.secondOrNull()) // 2
}
```

---

## **4️⃣ Расширения для `nullable` типов**

Функции расширения могут вызываться даже на **null**, что полезно для безопасных операций.

```kotlin
fun String?.isNullOrEmpty(): Boolean {
    return this == null || this.isEmpty()
}

fun main() {
    val text: String? = null
    println(text.isNullOrEmpty()) // true
}
```

🔹 **`this` может быть `null`**, поэтому внутри функции нужно обрабатывать этот случай.

---

## **5️⃣ Расширение для классов, которые мы не можем изменить**

Допустим, мы работаем с Java-классом и не можем его изменить. Можно добавить в него новые методы:

```kotlin
fun java.util.Date.format(): String {
    val formatter = java.text.SimpleDateFormat("yyyy-MM-dd")
    return formatter.format(this)
}

fun main() {
    val date = java.util.Date()
    println(date.format()) // Выведет дату в формате "2025-02-10"
}
```

🔹 Это позволяет **улучшить работу с устаревшими API** без наследования.

---

## **6️⃣ Функции расширения vs Обычные методы**

|**Особенность**|**Обычный метод**|**Функция расширения**|
|---|---|---|
|Доступ к `private` и `protected`|✅ Да|❌ Нет|
|Может быть `override`|✅ Да|❌ Нет|
|Требует изменения кода класса|✅ Да|❌ Нет|
|Работает с `null`|❌ Нет|✅ Да (если `nullable`)|

## **7️⃣ Расширение операторов**

Можно добавлять операторы через функции расширения.

```kotlin
operator fun String.times(n: Int): String {
    return this.repeat(n)
}

fun main() {
    println("Hello " * 3) // Hello Hello Hello 
}
```

## **8️⃣ Расширение `Companion Object`**

Если у класса есть `companion object`, можно добавить ему новые функции.

```kotlin
class User(val name: String) {
    companion object
}

fun User.Companion.createGuest() = User("Guest")

fun main() {
    val guest = User.createGuest()
    println(guest.name) // Guest
}
```

---

## **9️⃣ Инфиксные функции расширения**

Можно писать **красивый читаемый код** с `infix`.

```kotlin
infix fun Int.multiplyBy(n: Int): Int {
    return this * n
}

fun main() {
    println(5 multiplyBy 3) // 15
}
```

## **🔟 Итоги: что нужно знать для собеседования?**

### **🔹 Что такое функции расширения?**

- Позволяют **добавлять методы к существующим классам** без изменения их кода.
- Используют синтаксис `fun Класс.метод() {}`.

### **🔹 Ключевые особенности**

- **Не изменяют исходный класс**.
- **Не имеют доступа к `private` и `protected` полям**.
- **Могут работать с `nullable` типами**.
- **Не могут переопределять существующие методы класса**.

### **🔹 Где применяются?**

- Упрощение работы со стандартными классами (`String`, `List`, `Map`).
- Улучшение API Java-классов.
- Улучшение читаемости кода.

### **🔹 Чем функции расширения лучше обычных методов?**

- Позволяют писать **более читаемый и выразительный код**.
- Уменьшают необходимость наследования и увеличивают **гибкость**.
