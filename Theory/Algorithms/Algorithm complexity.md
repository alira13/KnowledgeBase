# Сложность алгоритма

Оценка того, как растут **время** (временна́я сложность) и **память** (пространственная/ёмкостная сложность) при увеличении размера входа `n`. Нужна, чтобы сравнивать алгоритмы независимо от железа.

## Big-O (нотация «О большое»)
**O(f(n))** — верхняя граница роста: как ведёт себя алгоритм в **худшем** случае при больших `n`. Отбрасываем константы и младшие члены: `O(3n + 5) = O(n)`, `O(n² + n) = O(n²)`.

Также встречаются: **Ω (омега)** — нижняя граница (лучший случай), **Θ (тета)** — точная (совпадают верхняя и нижняя).

## Классы сложности (от лучшего к худшему)
| O | Название | Пример | При n=1000 |
|---|---|---|---|
| **O(1)** | константная | доступ по индексу в массиве, вставка в HashMap | 1 |
| **O(log n)** | логарифмическая | бинарный поиск, сбалансированное дерево | ~10 |
| **O(n)** | линейная | проход по списку, линейный поиск | 1 000 |
| **O(n log n)** | линеаром. | быстрая/слиянием сортировка | ~10 000 |
| **O(n²)** | квадратичная | вложенные циклы, пузырьковая сортировка | 1 000 000 |
| **O(2ⁿ)** | экспоненциальная | перебор подмножеств, наивный Фибоначчи | огромно |
| **O(n!)** | факториальная | перебор перестановок (коммивояжёр) | катастрофа |

## Как оценивать (правила)
- **Последовательные** блоки — складываются, берётся больший: `O(n) + O(n²) = O(n²)`.
- **Вложенные** циклы — перемножаются: цикл в цикле по n → `O(n²)`.
- **Деление задачи пополам** на каждом шаге → `log n` (бинарный поиск, обход дерева).
- Константы и коэффициенты игнорируются.

## Лучший / средний / худший случай
Big-O обычно описывает **худший** случай. Пример: поиск в `HashMap` — в среднем `O(1)`, но при плохом hashCode (все в один бакет) деградирует до `O(n)` (в Java 8+ — до `O(log n)` за счёт превращения бакета в дерево). См. [[Classes. toString, equals, hashCode, copy]], [[Trees. Balanced. Red-black]].

## Пространственная сложность
Дополнительная память, которую требует алгоритм (не считая входа). Пример: рекурсия хранит кадры на стеке → `O(глубины)`; сортировка слиянием — `O(n)` доп. памяти, а быстрая — `O(log n)`. См. [[Stack and heap]], [[Call stack]].
