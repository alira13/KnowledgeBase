Паттерн **"Два указателя"** (Two Pointers) — это эффективная техника для решения алгоритмических задач, в которых нужно обрабатывать массивы или строки. Он позволяет сократить временную сложность решения за счёт использования двух указателей, которые перемещаются по структуре данных определённым образом.

### 🔹 **Основная идея**

Вместо использования вложенных циклов или рекурсий, два указателя помогают оптимизировать процесс поиска, обработки или сортировки данных. В зависимости от задачи, указатели могут двигаться:

- навстречу друг другу (например, при поиске палиндромов);
- в одном направлении (например, при поиске подмассивов);
- с разной скоростью (например, при поиске циклов в списках).

### 🔹 **Типичные применения**

1. **Два указателя с двух концов**  
    Используется, когда нужно обрабатывать массив с обоих краёв. **Пример:** Проверка, является ли строка палиндромом.
    
    ```kotlin
    fun isPalindrome(s: String): Boolean {
        var left = 0
        var right = s.length - 1
        while (left < right) {
            if (s[left] != s[right]) return false
            left++
            right--
        }
        return true
    }
    ```
    
    **Временная сложность: O(n),** так как каждый символ проверяется только один раз.
    
2. **Два указателя в одном направлении**  
    Часто используется для поиска подмассивов с определёнными свойствами. **Пример:** Нахождение суммы двух чисел в отсортированном массиве.
    
    ```kotlin
    fun twoSum(nums: IntArray, target: Int): IntArray {
        var left = 0
        var right = nums.size - 1
        while (left < right) {
            val sum = nums[left] + nums[right]
            when {
                sum == target -> return intArrayOf(left, right)
                sum < target -> left++
                else -> right--
            }
        }
        return intArrayOf()
    }
    ```
    
    **Временная сложность: O(n),** так как каждое число проверяется не более одного раза.
    
### 🔹 **Когда применять паттерн "Два указателя"?**

✅ Когда данные отсортированы.  
✅ Когда можно обработать массив/строку, двигаясь от начала и конца.  
✅ Когда задача связана с поиском подмассивов или подстрок.  
✅ Когда требуется обнаружение циклов в списках.


В задачах, когда мы имеем дело с отсортированными массивами (или связанными списками) и должны найти набор элементов, которые выполняют определенные ограничения
Набор элементов может быть парой, триплетом или даже подмассив. 

Пример
Учитывая массив отсортированных чисел и целевую сумму, найдите пару в массиве, сумма которых равна данной цели. 
Чтобы решить эту проблему, мы можем рассмотреть каждый элемент один за другим (обозначенный первым указателем) и итерация через оставшиеся элементы (обозначенные вторым указателем), чтобы найти пару с данной суммой. 

Решение
Учитывая, что входной массив сортируется, эффективным подходом будет начало с одного указателя в начале и еще один указатель в конце. На каждом этапе мы проверим, что цифры, указанные двумя указателями, составляют к целевой сумме. Если они этого не делают, у нас есть два варианта: 
 - Если сумма двух чисел, указанных двумя указателями, больше, чем целевая сумма, это означает, что нам нужна пара с меньшей суммой. Чтобы изучить больше пар, мы можем уменьшить конечный указатель. 
 - Если сумма двух чисел, указанных двумя указателями, меньше целевой суммы, это означает, что нам нужна пара с большей суммой. Чтобы изучить больше пар, мы можем увеличить начальный указатель. Вот визуальное представление этого алгоритма: Временная сложность приведенного выше алгоритма будет.
