Array<Int>, IntArray

Статический массив - структура данных с элементами одинакового типа, фиксированным количеством элементов, и каждому элементу данных присваивается положительное числовое значение (индекс), который соответствует позиции элемента в массиве.
 - массив представляет собой непрерывный кусок памяти 
 - размер памяти имеет фиксированный размер, и определяется количеством элементов умноженным на размер элемента(опредетяется типом данных элемента)
 - хранит один тип данных
 - индексы являются непрерывными целыми числами
 - имя массива является указателем на стартовый адрес массива(адрес -элемента)

##### Типизация по структуре
- Одномерные - состоит из нескольких элементов, объединенных под одним именем. Для обращения к элементу нужно указать только один индекс
- Многомерные - это массив, в котором каждый элемент является другим массивом. Для обращения к элементу массива требуется указать несколько индексов

##### Операции
**Чтение элемента O(1)**

Обращение к элементу массива происходит по адресу. Так как элементы массива в памяти расположены последовательно, то адрес вычисляется по формуле:

Aq=a(имя массива)+k(размер одного эл-та)*n(индекс)

**a** — _начальный адрес, это адрес ячейки памяти, начиная с которой размещается массив. Он формируется во время выделения памяти под массив.
**n** — индекс, указывается пользователем
**k** — количество памяти (для данного типа данных). Определяем, когда указываем тип хранения массива

т.к. все эти переменные являются const то и результат будет const, т.о сложность=O(1)

**Запись элемента O(1)**
Осуществляется таким же образом. Находится адрес элемента с указанным индексом и помещается туда значение
ar[1]=value

**Добавление O(n)**
Для статических массивов в классическом понимании нет удалений и добавлений элементов с изменением размера массива. Такие операции можно симитировать за счет первоначального создания массива большего размера и его неполного заполнения значимыми значениями.
При добавлении элемента в конец массива, происходит просто заполнение его значением и сложность будет O(1) как при записи, но при добавлении элемента в начало перед записью валидного значения нужно произвести сдвиг всех элементов(в худшем случае) вправо со сложностью O(n), поэтому при добавлении элемента сложность O(n)

**Удаление O(n)**
Аналогично при удалении последнего элемента будет просто запись значения по умолчанию и сложность O(1), но при удалении первого нужен будет сдвиг всех остальных элементов и сложность будет O(n)

##### Преимущества и недостатки статических массивов

++ сложность чтения и записи константна
++ эффективное использование памяти. Массивы содержат только данные, поэтому память не расходуется на указатели и другую форматирующую информацию. Кроме того, не требуется использовать метку конца записи для элементов массива, так как все элементы массива имеют одинаковый размер.
++ локальность в памяти. Одной из наиболее распространенных идиом программирования является обработка элементов структуры данных в цикле. Массивы хорошо подходят для операций такого типа, поскольку обладают отличной локальностью в памяти. В современных компьютерных архитектурах физическая непрерывность последовательных обращений к данным помогает использовать высокоскоростную кэш-память.
-- удаление и вставка невозможна без сдвига других элементов, что приводит к сложности O(n)
-- для хранения необходим кусок непрерывной памяти, что для больших массивов создает проблему
-- при изменении размера массива придется создавать новый

##### Применение
Нужно использовать массивы, когда у вас есть специальные низкоуровневые требования, которым необходимо удовлетворить. Например, если у вас есть требования к производительности, превышающие требования обычных приложений, или вам нужно создать собственные структуры данных. Если у вас нет подобных ограничений, используйте вместо них коллекции.

##### Реализация в Java
**Создание**
Чтобы создать массив, необходимо использовать ключевое слово _new_ с указанием его размерности и типа:
```
int [] array =new int[10];
```

- оператор _new_ выделяет в памяти (_heap_, куче) место под хранение десяти значений типа _int_
- затем он возвращает ссылку (будет храниться в стеке) на начало области памяти (совпадает с первым элементом), выделенной под массив
- ссылка помещается в переменную _array_ того же типа, что и массив

##### Реализация в Kotlin

**Иерархия**

В рамках коллекций в Java/Kotlin класс Array находится вне этой иерархии. А стоит как отдельный класс. Не надо путать с ArrayList

![](<images/Untitled.png>)

**Свойства массивов**

- всегда mutable
- инваририантны, не могут быть конвертированы в any

**Виды массивов Kotlin**

- generic-массивы Array<Int>, Array<Boolean> - конвертируются в Java Array<Integer>, а значит могут быть Null
- массивы примитивных типов - intArrayOf, booleanArrayOf конвертируются в Java int[], всегда не null. Эти классы не имеют отношения наследования к классу Array, но имеют тот же набор функций и свойств.

`Array<Int>` — это `Integer[]` под капотом, в то время как `IntArray` — это `int[]`. Это означает, что когда вы поместите `Int` в `Array<Int>`, он всегда будет в **boxed.** В случае `IntArray` **boxed** не произойдет, потому что он преобразуется в примитивный массив Java.
