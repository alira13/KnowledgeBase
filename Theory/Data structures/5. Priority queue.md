Приоритетная очередь — это структура данных, в которой каждый элемент имеет приоритет, и элементы извлекаются в порядке приоритета, а не в порядке добавления. Элементы с более высоким приоритетом извлекаются раньше. В Java и Kotlin приоритетная очередь может быть реализована с использованием стандартных классов `PriorityQueue`.

### Реализация приоритетной очереди в Java

Java предоставляет класс `PriorityQueue`, в котором элементы автоматически упорядочиваются по естественному порядку (или с использованием компаратора, если его указать). По умолчанию `PriorityQueue` является **минимальной очередью**, то есть элементы с меньшим значением извлекаются первыми.

#### Пример использования `PriorityQueue` в Java

```
import java.util.PriorityQueue;

public class PriorityQueueExample {
    public static void main(String[] args) {
        // Приоритетная очередь для целых чисел (по умолчанию — минимальная очередь)
        PriorityQueue<Integer> queue = new PriorityQueue<>();

        // Добавление элементов
        queue.add(5);
        queue.add(1);
        queue.add(3);

        // Извлечение элементов в порядке приоритета
        System.out.println("Elements in priority order:");
        while (!queue.isEmpty()) {
            System.out.println(queue.poll()); // Вывод: 1, 3, 5
        }
    }
}

```


#### Пример приоритетной очереди с пользовательским компаратором

Если нужно изменить порядок сортировки (например, для реализации **максимальной очереди**), можно передать в `PriorityQueue` компаратор:
```
import java.util.PriorityQueue;
import java.util.Comparator;

public class MaxPriorityQueueExample {
    public static void main(String[] args) {
        // Максимальная приоритетная очередь с обратным компаратором
        PriorityQueue<Integer> maxQueue = new PriorityQueue<>(Comparator.reverseOrder());

        // Добавление элементов
        maxQueue.add(5);
        maxQueue.add(1);
        maxQueue.add(3);

        // Извлечение элементов в порядке приоритета (максимальный первый)
        System.out.println("Elements in descending priority order:");
        while (!maxQueue.isEmpty()) {
            System.out.println(maxQueue.poll()); // Вывод: 5, 3, 1
        }
    }
}

```

### Примечания

- **Комплексность операций**: Операции добавления и удаления элемента имеют сложность O(log⁡n)O(\log n)O(logn) благодаря тому, что `PriorityQueue` построена на базе **двоичной кучи**.
- **Использование с пользовательскими классами**: Если элементы приоритетной очереди являются объектами пользовательского типа, они должны реализовать `Comparable` или использовать компаратор при создании очереди.

Эти реализации позволяют легко управлять элементами по приоритету и обеспечивают эффективное добавление и извлечение элементов в нужном порядке.


Для реализации приоритетной очереди на Java без использования стандартных структур данных можно создать класс `PriorityQueue`, в котором будет массив фиксированного размера для хранения элементов. Очередь должна обеспечивать добавление элементов с приоритетом, сортировку их в порядке приоритета и извлечение элементов с наивысшим приоритетом.

Вот пример реализации:
```
class PriorityQueue {
    private int[] queue;  // массив для хранения элементов очереди
    private int size;     // текущее количество элементов в очереди
    private int capacity; // максимальная емкость очереди

    // Конструктор, задающий размер очереди
    public PriorityQueue(int capacity) {
        this.capacity = capacity;
        this.queue = new int[capacity];
        this.size = 0;
    }

    // Метод для добавления элемента в очередь с приоритетом
    public void insert(int element) {
        if (size == capacity) {
            System.out.println("Очередь заполнена, невозможно вставить элемент.");
            return;
        }

        int i;
        // Проходим по очереди с конца к началу, чтобы найти место для нового элемента
        for (i = size - 1; i >= 0; i--) {
            // Если элемент в очереди меньше нового, сдвигаем его вправо
            if (queue[i] < element) {
                queue[i + 1] = queue[i];
            } else {
                break;
            }
        }

        // Вставляем новый элемент в подходящую позицию
        queue[i + 1] = element;
        size++;
    }

    // Метод для удаления элемента с наивысшим приоритетом (первый в очереди)
    public int remove() {
        if (size == 0) {
            System.out.println("Очередь пуста.");
            return -1;
        }

        // Извлекаем элемент с наивысшим приоритетом (первый элемент)
        return queue[--size];
    }

    // Метод для получения элемента с наивысшим приоритетом без удаления
    public int peek() {
        if (size == 0) {
            System.out.println("Очередь пуста.");
            return -1;
        }

        return queue[size - 1];
    }

    // Метод для проверки, пуста ли очередь
    public boolean isEmpty() {
        return size == 0;
    }

    // Метод для проверки, заполнена ли очередь
    public boolean isFull() {
        return size == capacity;
    }
}

```

### Описание реализации:

1. **Добавление элемента**: Метод `insert` добавляет элемент в очередь, при этом элементы сортируются в порядке убывания приоритетов (чем больше значение, тем выше приоритет). Мы проходим с конца массива, чтобы найти подходящую позицию для нового элемента.
2. **Удаление элемента**: Метод `remove` удаляет и возвращает элемент с наивысшим приоритетом, который находится в конце массива.
3. **Просмотр элемента с наивысшим приоритетом**: Метод `peek` возвращает элемент с наивысшим приоритетом, не удаляя его из очереди.
4. **Проверка на пустоту**: Метод `isEmpty` проверяет, пустая ли очередь.
5. **Проверка на заполненность**: Метод `isFull` проверяет, заполнена ли очередь.

### Пример использования:

```
public class Main {
    public static void main(String[] args) {
        PriorityQueue priorityQueue = new PriorityQueue(5);
        
        priorityQueue.insert(10);
        priorityQueue.insert(30);
        priorityQueue.insert(20);
        priorityQueue.insert(40);
        priorityQueue.insert(5);

        System.out.println("Элемент с наивысшим приоритетом: " + priorityQueue.peek()); // Ожидается 40

        while (!priorityQueue.isEmpty()) {
            System.out.println("Удален элемент: " + priorityQueue.remove());
        }
    }
}

```

Этот код создаёт очередь на 5 элементов и выводит их в порядке приоритетов.
