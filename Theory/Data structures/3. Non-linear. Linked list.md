LinkedList из JavaUtils

+ Это структура, которая решает проблему производительности, если нам приходится часто добавлять и удалять данные. Данные в связном списке хранятся не подряд, а вразброс.
+ Чтобы решить проблему необходимости непрерывного куска памяти для хранения массива, придумали связные списки

Односвязный список

Односвязный список - структура данных, которая содержит набор узлов, в каждом из которых содержится значение и ссылка на следующйи узел. Первый элемент списка - Head, последний - Tail, он ссылается на NULL.

https://habr.com/ru/articles/337558/
##### Запись/чтение значения элемента(доступ к элементу) O(n)
##### Добавление нового элемента O(1)
##### Удаление элемента O(1)
