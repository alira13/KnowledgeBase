Очередь (queue) — это структура данных, работающая по принципу **FIFO** (First In, First Out, т.е. «первый вошёл — первый вышел»). В очереди элементы добавляются в один конец (хвост), а удаляются из другого (голова). В связи с этим, очередь часто используется там, где требуется обработка данных в порядке их поступления.

### Основные характеристики очереди

1. **Структура:**  
    Очередь можно представить как последовательность элементов, где:
    
    - Новый элемент добавляется в конец (хвост).
    - Элемент извлекается из начала (голова).
2. **Сложность операций:**
    - **Добавление элемента:** O(1), так как добавление происходит в конец очереди.
    - **Удаление элемента:** O(1), так как удаление происходит с начала очереди.
    - **Чтение элемента с начала:** O(1), поскольку доступ к первому элементу всегда мгновенный.

### Типы очередей

1. **Простая очередь** — стандартная FIFO-очередь.
2. **Двусторонняя очередь (deque)** — позволяет добавлять и удалять элементы с обеих сторон.
3. **Приоритетная очередь** — элементы извлекаются не в порядке добавления, а в зависимости от приоритета.

### Реализация очереди

В Java и Kotlin можно реализовать очередь несколькими способами, используя массивы, связные списки или встроенные классы из стандартной библиотеки.

### Пример реализации очереди на основе массива

#### На Java


```
import java.util.NoSuchElementException;

public class ArrayQueue {
    private int[] queue;
    private int front;   // индекс первого элемента
    private int rear;    // индекс последнего элемента
    private int size;    // количество элементов
    private int capacity;

    public ArrayQueue(int capacity) {
        this.capacity = capacity;
        queue = new int[capacity];
        front = 0;
        rear = -1;
        size = 0;
    }

    // Добавление элемента в очередь
    public void enqueue(int item) {
        if (size == capacity) throw new IllegalStateException("Queue is full");
        rear = (rear + 1) % capacity; // перемещение заднего указателя
        queue[rear] = item;
        size++;
    }

    // Удаление элемента из очереди
    public int dequeue() {
        if (size == 0) throw new NoSuchElementException("Queue is empty");
        int item = queue[front];
        front = (front + 1) % capacity; // перемещение переднего указателя
        size--;
        return item;
    }

    // Получение первого элемента
    public int peek() {
        if (size == 0) throw new NoSuchElementException("Queue is empty");
        return queue[front];
    }

    // Проверка на пустоту
    public boolean isEmpty() {
        return size == 0;
    }

    // Получение размера очереди
    public int getSize() {
        return size;
    }
}

```


### Реализация очереди с помощью стандартных классов

В Java и Kotlin есть встроенные классы для работы с очередями. Например:

- **Java:** `Queue` интерфейс и его реализации, такие как `LinkedList`, `ArrayDeque`, `PriorityQueue`.
- **Kotlin:** также может использовать те же реализации из Java или использовать **MutableList** для создания очереди.

#### Пример использования `LinkedList` в Java


```
import java.util.LinkedList;
import java.util.Queue;

public class QueueExample {
    public static void main(String[] args) {
        Queue<Integer> queue = new LinkedList<>();
        queue.add(1);
        queue.add(2);
        queue.add(3);

        System.out.println(queue.poll()); // Извлекает и удаляет первый элемент (1)
        System.out.println(queue.peek()); // Возвращает первый элемент без удаления (2)
    }
}
```

#### Пример использования `ArrayDeque` в Kotlin

```
fun main() {
    val queue: ArrayDeque<Int> = ArrayDeque()
    queue.add(1)
    queue.add(2)
    queue.add(3)

    println(queue.removeFirst()) // Извлекает и удаляет первый элемент (1)
    println(queue.first())       // Возвращает первый элемент без удаления (2)
}
```

### Заключение

Очереди — это простой и эффективный способ организовать данные в порядке поступления. В зависимости от задачи и требований к производительности, можно выбрать подходящую реализацию очереди.


Очередь на основе связного списка в Java можно реализовать с помощью узлов (`Node`), где каждый элемент имеет ссылку на следующий элемент. В такой реализации:

- Головной узел (head) будет указывать на первый элемент очереди, из которого данные извлекаются.
- Хвостовой узел (tail) указывает на последний элемент, в который данные добавляются.

### Пример реализации очереди на основе связного списка

```
public class LinkedListQueue<T> {
    private Node<T> front; // Указывает на начало очереди (голова)
    private Node<T> rear;  // Указывает на конец очереди (хвост)
    private int size;      // Текущий размер очереди

    // Узел очереди
    private static class Node<T> {
        private T data;
        private Node<T> next;

        public Node(T data) {
            this.data = data;
            this.next = null;
        }
    }

    public LinkedListQueue() {
        this.front = null;
        this.rear = null;
        this.size = 0;
    }

    // Метод добавления элемента в очередь
    public void enqueue(T item) {
        Node<T> newNode = new Node<>(item);

        // Если очередь пуста, новый узел становится и front, и rear
        if (rear == null) {
            front = newNode;
            rear = newNode;
        } else {
            rear.next = newNode; // Присоединяем новый узел к "хвосту" очереди
            rear = newNode;      // Обновляем указатель на хвост
        }
        size++;
    }

    // Метод удаления элемента из очереди
    public T dequeue() {
        if (front == null) {
            throw new IllegalStateException("Queue is empty");
        }

        T data = front.data;
        front = front.next; // Перемещаем указатель на следующий узел
        size--;

        // Если очередь стала пустой, rear также обнуляем
        if (front == null) {
            rear = null;
        }

        return data;
    }

    // Метод получения первого элемента (без удаления)
    public T peek() {
        if (front == null) {
            throw new IllegalStateException("Queue is empty");
        }
        return front.data;
    }

    // Проверка на пустоту
    public boolean isEmpty() {
        return size == 0;
    }

    // Получение размера очереди
    public int getSize() {
        return size;
    }

    public static void main(String[] args) {
        LinkedListQueue<Integer> queue = new LinkedListQueue<>();
        
        // Добавление элементов
        queue.enqueue(1);
        queue.enqueue(2);
        queue.enqueue(3);
        
        // Получение и удаление первого элемента
        System.out.println("Dequeued: " + queue.dequeue()); // Вывод: 1
        System.out.println("Front element: " + queue.peek()); // Вывод: 2
        System.out.println("Queue size: " + queue.getSize()); // Вывод: 2
    }
}

```

### Объяснение работы

1. **`enqueue(T item)`** — добавляет элемент в конец очереди:
    
    - Создаётся новый узел с переданным значением.
    - Если очередь пуста, то этот узел становится и `front`, и `rear`.
    - Если очередь не пуста, то новый узел добавляется после `rear`, и указатель `rear` обновляется на новый узел.
2. **`dequeue()`** — удаляет и возвращает элемент из начала очереди:
    
    - Проверяет, пуста ли очередь. Если да, выбрасывается исключение.
    - Если очередь не пуста, удаляется узел `front`, и указатель `front` перемещается на следующий элемент.
    - Если после удаления очередь опустела, также обнуляется указатель `rear`.
3. **`peek()`** — возвращает элемент из начала очереди без его удаления.
    
4. **`isEmpty()`** — проверяет, пуста ли очередь.
    
5. **`getSize()`** — возвращает текущий размер очереди.
    

### Сложность операций

- **Добавление (enqueue)** — O(1)O(1)O(1), так как добавление происходит в конец списка.
- **Удаление (dequeue)** — O(1)O(1)O(1), так как удаление происходит с начала списка.
- **Чтение (peek)** — O(1)O(1)O(1), доступ к первому элементу мгновенный.

Такая реализация удобна и эффективна для очередей, где операции добавления и удаления происходят часто.
