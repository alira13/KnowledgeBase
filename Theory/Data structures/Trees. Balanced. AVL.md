# АВЛ-дерево (AVL-tree)

Самобалансирующееся [[Trees. Binary search tree|бинарное дерево поиска]]. Названо по авторам — Адельсон-Вельский и Ландис (1962).

## Инвариант баланса
Для **каждого** узла высоты левого и правого поддеревьев отличаются не более чем на 1 (balance factor ∈ {−1, 0, +1}). За счёт этого высота гарантированно **O(log n)**.

## Балансировка — повороты
При вставке/удалении, если баланс нарушился, дерево восстанавливают вращениями:
- **LL** → правый поворот;
- **RR** → левый поворот;
- **LR** → левый, затем правый;
- **RL** → правый, затем левый.

## Сложности
| Операция | Время |
|---|---|
| Поиск | O(log n) |
| Вставка | O(log n) |
| Удаление | O(log n) |

## AVL vs Красно-чёрное дерево
- **AVL** строже сбалансировано → **быстрее поиск**, но **больше поворотов** при вставке/удалении.
- **Красно-чёрное** — слабее баланс, но дешевле модификация → выгоднее при частых вставках/удалениях. См. [[Trees. Balanced. Red-black]].
