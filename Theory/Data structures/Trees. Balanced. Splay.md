# Расширяющееся дерево (Splay tree)

Самоорганизующееся [[Trees. Binary search tree|бинарное дерево поиска]]. После **каждого** обращения к узлу (поиск, вставка) этот узел перемещается в **корень** специальной операцией **splay** (серия поворотов).

## Идея
Не поддерживает строгий инвариант баланса. Вместо этого использует **принцип локальности**: недавно использованные элементы оказываются ближе к корню и доступны быстрее. Хорош, когда обращения неравномерны (часть ключей запрашивается чаще).

## Splay — типы шагов
- **Zig** — узел является потомком корня (один поворот).
- **Zig-zig** — узел и родитель с одной стороны (два одинаковых поворота).
- **Zig-zag** — узел и родитель с разных сторон (два разнонаправленных поворота).

## Сложности
- Отдельная операция в худшем случае — **O(n)** (дерево может быть вырожденным).
- Но **амортизированно O(log n)** — усреднённо по последовательности операций.

## Плюсы/минусы
- (+) Простая реализация, отличная кэш-локальность, эффективно при повторных обращениях к одним ключам.
- (−) Нет гарантии O(log n) на одну операцию; каждое чтение изменяет структуру (проблема для многопоточного чтения).
