# Декартово дерево (Treap)

**Treap** = Tree + Heap. Каждый узел хранит два значения:
- **ключ (key)** — по нему структура является [[Trees. Binary search tree|деревом поиска]] (BST): левое < узел < правое;
- **приоритет (priority)** — по нему структура является **кучей** (priority родителя выше приоритетов детей).

## Идея
Приоритеты назначаются **случайно**. Комбинация «BST по ключу + heap по приоритету» даёт с высокой вероятностью сбалансированное дерево высотой **O(log n)** без явных правил балансировки — баланс достигается рандомизацией.

## Операции
- **split(T, key)** — разбить на два дерева: ключи < key и ≥ key.
- **merge(T1, T2)** — слить два дерева (все ключи T1 < ключей T2).
- Вставка/удаление/поиск выражаются через split/merge, все — **O(log n)** в среднем.

## Разновидность: Treap по неявному ключу
Ключ = позиция элемента (индекс), а не значение. Позволяет за O(log n): вставку/удаление по индексу, разворот отрезка, операции на подотрезках массива — используется в спортивном программировании.

## Плюсы/минусы
- (+) Простая реализация относительно AVL/RB, гибкие split/merge.
- (−) Балансировка вероятностная (не гарантированная), зависит от генератора случайных чисел.
