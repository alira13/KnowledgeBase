# Сериализация и десериализация

**Сериализация** – преобразование объектов в строки.  
**Десериализация** – преобразование строк или набора байт в объекты.  
## JSON (JavaScript Object Notation)

JSON – представление любых объектов в виде пары *ключ-значение*.  
Наиболее распространенный формат представления объекта в строку.

```json
[  
  {  
    "id": 1,  
    "name": "Ivan",  
    "email": "Ivan@mail.ru",  
    "registered_at": "11.01.2021"  
  },  
  {  
    "id": 2,  
    "name": "Maria",  
    "email": "Maria@mail.ru",  
    "registered_at": "11.01.2022"  
  }  
]
```

`kotlinx.serialization` – библиотека для работы с JSON

### Использование:

1. Подключить библиотеку.
2. Пометить класс аннотацией `@Serializable` – позволяет сгенерировать код для сериализации и десериализации данного объекта.
3. Если имя поля класса не совпадает с именем в файле ключа json, можно пометить поле аннотацией @SerialName. В идеале добавлять эти аннотации для всех полей для ясности и читаемости+после обфускации(кодирования имен кода) имена ключей и переменных будут отличаться, и код перестанет работать

```kotlin
@Serializable  
data class User(  
    @SerialName("id") val id: Int,  
    @SerialName("name") val name: String,  
    @SerialName("email") val email: String,  
    @SerialName("registered_at") val registeredAt: String  
)  
  
fun serializeUser(user: User): String {  
    return Json.encodeToString(user)  
}  
  
fun deserializeUser(json: String): User {  
    return Json.decodeFromString<User>(json)  
}
```

Интерфейс Serializable позволяет преобразовывать объект в массив байт
enum неявно реализуют Serializable

### Serializable vs Parselazible
Оба преобразуют объект в набор байтов и обратно
Когда реализуем  Serializable, нам ничего делать не надо и все делаться под капотом за нас. Но этот процесс очень медленный

При использовании Parselazible нам необходимо самим переопределить методы интерфейса Parselazible. Но есть плагин, который сможет сделать это за нас kotlin-parselize. Нам нужно только поставить аннотацию @Parselize


| **Характеристика**     | **Serializable**                                               | **Parcelable (@Parcelize)**                                                        |
| ---------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **Происхождение**      | Стандартный Java интерфейс                                     | Android-специфичный интерфейс                                                      |
| **Реализация**         | Автоматическая с помощью reflection                            | Ручная реализация методов сериализации (автоматическая с `@Parcelize` в Kotlin)    |
| **Производительность** | Медленнее из-за reflection                                     | Быстрее, не использует reflection                                                  |
| **Применение**         | Подходит для простых случаев, межплатформенная передача данных | Рекомендуется для Android, особенно для критических по производительности ситуаций |
| **Сложность**          | Простая реализация, но может быть неэффективной                | Более сложная реализация без `@Parcelize`, но эффективная                          |

Рефлексия в Java — это механизм, который позволяет программе анализировать и изменять структуру классов, интерфейсов, полей и методов во время выполнения.
