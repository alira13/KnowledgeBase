### Реляционные базы данных

В основе реляционных БД лежит мощный математический аппарат — реляционная алгебра, которая описывает связи между данными. Данные в реляционной БД хранятся в виде таблиц.

Опираясь на знания об ООП:
- **Сущность (Entity)** — это класс.
- **Запись (Record)** — строка таблицы, описывающая объект класса.
- **Атрибут (Attribute)** — столбец таблицы, аналог поля класса.
- **Id (Primary Key, PK)** — первичный ключ, уникальный идентификатор записи.
- **Внешний ключ (Foreign Key, FK)** — атрибут, связывающий сущности.

#### Пример таблицы

|Id|Name|Color|Price|
|---|---|---|---|
|1|Свитер|Желтый|100|
|2|Юбка|Черный|200|

### Проектирование баз данных

Проектирование БД — это процесс описания сущностей и связей между ними.

#### Виды отношений:

1. **Один ко многим** — у одной сущности могут быть несколько связанных записей в другой таблице. Реализуется через внешний ключ.
2. **Многие ко многим** — решается с помощью промежуточной таблицы.
3. **Один к одному** — редкое отношение, реализуется либо уникальным столбцом, либо отдельной таблицей.

### SQL — язык запросов

SQL — декларативный язык программирования для работы с БД. Основные группы операторов:

1. **DDL (Data Definition Language)** — создание и управление таблицами:
    - `CREATE` — создание таблицы.
    - `ALTER` — изменение структуры.
    - `DROP` — удаление.
2. **DML (Data Manipulation Language)** — манипуляция данными:
    - `SELECT` — выборка данных.
    - `INSERT` — добавление.
    - `UPDATE` — изменение.
    - `DELETE` — удаление.
3. **DCL (Data Control Language)** — управление доступом к данным.

### SQLite — стандарт в Android

SQLite — легковесная СУБД, используемая в Android. Данные хранятся в файле во внутренней памяти приложения, доступ к которому имеют только владельцы приложения. SQLite безопасен, но требует много кода.

### Room — библиотека для работы с SQLite

Room упрощает работу с SQLite, автоматически генерируя код. Основные преимущества:
- **Простота** — минимизация кода.
- **Производительность** — оптимизация запросов.
- **Безопасность** — контроль целостности данных.
- **Гибкость** — поддержка разных типов данных и интеграция с Android-компонентами (`LiveData`, `ViewModel`).

ORM — концепция, упрощающая работу с БД через объектную модель. Room — это ORM-библиотека.

#### Преимущества ORM:

- Упрощённое взаимодействие с БД.
- Автоматическое управление транзакциями.
- Повышенная производительность.
- Поддержка нескольких СУБД.

### Работа с Room

1. **Создание класса сущности** (`@Entity`).
2. **Добавление аннотаций к полям** (`@PrimaryKey`, `@ColumnInfo`).
3. **Создание DAO** — интерфейса для взаимодействия с БД.
    
4. **Создание экземпляра БД** с помощью билдера.
    

#### Миграции:

- **fallbackToDestructiveMigration** — сброс данных при изменении схемы.
    
- **Ручная миграция** — сохранение данных при обновлении структуры БД.
