**WebSocket** — это протокол связи, который позволяет устанавливать **двустороннюю связь** между клиентом и сервером через одно долгоживущее TCP-соединение. Это позволяет обмениваться данными в режиме реального времени без необходимости постоянных HTTP-запросов.

## **Основные особенности**

1. **Двусторонняя связь**  
    WebSocket позволяет клиенту и серверу обмениваться данными в обоих направлениях, что делает его идеальным для приложений реального времени.
    
2. **Низкая задержка**  
    Поскольку соединение остаётся открытым, задержка при передаче данных значительно ниже по сравнению с традиционными HTTP-запросами.
    
3. **Эффективность**  
    WebSocket использует меньше ресурсов, чем открытие новых HTTP-соединений для каждого запроса.
    
4. **Безопасность**  
    WebSocket может использовать шифрование для обеспечения безопасности передаваемых данных через протокол `wss://`.
    

## **Примеры использования**

- **Онлайн-игры**: для мгновенной передачи данных между клиентом и сервером.
    
- **Чат-приложения**: для обмена сообщениями в реальном времени.
    
- **Торговые платформы**: для мгновенной актуализации котировок.
    

## **Как работает**

1. **Установка соединения**  
    WebSocket начинается с установки соединения через HTTP (обычно используется стандартный порт 80 или защищенный порт 443).
    
2. **Обмен данными**  
    После успешной установки соединения клиент и сервер могут обмениваться данными в реальном времени.
    

## **Преимущества**

- **Высокая производительность**: поддерживает полнодуплексную связь, что повышает производительность сети.
    
- **Эффективность**: использует меньше ресурсов, чем традиционные методы.
    
- **Широкая поддержка**: поддерживается большинством современных браузеров и серверов.
