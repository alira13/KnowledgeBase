#### Способы отображения списков

- **Scroll+LinearLayout + View**  
  Есть `LinearLayout` для хранения самого списка и `View` для элементов списка. Помещаем его в Scroll для прокрутки. Через метод `inflate` создаем `View` для элемента списка, используя метод `findViewById`, и делаем эти действия для **всех** элементов списка, что может привести к тормозам в UI.

> [!NOTE]  
> [`LayoutInflater`](http://developer.android.com/reference/android/view/LayoutInflater.html) — это класс, который из содержимого layout-файла создает View-элемент. Метод, который это делает, называется **`inflate`**.  
> У метода есть несколько реализаций с различными параметрами, но все они используют друг друга, и результат выполнения — один: **View**.  
> **Параметры метода `inflate`:**  
> - **`resource`** — ID layout-файла, который будет использован для создания View, например, `R.layout.main`.  
> - **`root`** — родительский `ViewGroup`-элемент для создаваемого View. `LayoutParams` от этого `ViewGroup` присваиваются создаваемому View.  
> - **`attachToRoot`** — присоединять ли создаваемый View к root. Если `true`, то root становится родителем создаваемого View (эквивалентно `root.addView(View)`). Если `false`, то создаваемый View получает `LayoutParams` от root, но дочерним элементом не становится.

- **Spinner**  
  Выпадающий список, значения можно задать через `entities` или через `adapter`. Используется для небольших списков.

- **GridView** (устарел)  
  Отображение данных в табличной форме.

- **ListView** (устарел)  
  Использовался вместо `RecyclerView`.

- **RecyclerView**  
  Предпочтительный компонент для работы со списками.

### RecyclerView

это технология отображения списков, основанная на создании `View` не для всего списка, а только для элементов, видимых на экране, с небольшим запасом для плавного скролла. Также предусматривается переиспользование уже созданных `View` для новых элементов списка.

- **RecyclerView**  
  Класс, наследующийся от `ViewGroup`. Это значит, что со стороны Android SDK `RecyclerView` — это обычный UI-компонент, который можно добавлять в разметку, задавать атрибуты и создавать программно.  

- **ViewHolder**  
  Объект, который определяет, как именно должен выглядеть элемент списка на экране. Также отображает передаваемые данные, например, изображение, текст, кнопки, иконки. Экземпляры `ViewHolder` переиспользуются при исчезновении элементов списка из области видимости.

- **Adapter**  
  Основная задача `Adapter` — связывать набор данных с их визуальным представлением. Также `Adapter` отслеживает изменения в наборе данных.

- **LayoutManager**  
  Управляет расположением элементов внутри `RecyclerView`. В отличие от `ListView`, ограниченного вертикальной ориентацией, `RecyclerView` может размещать элементы вертикально, горизонтально или в виде таблицы. Это достигается благодаря гибкости `LayoutManager`. Также он обеспечивает правильную прокрутку списков.

- **ItemDecoration**  
  Позволяет добавить отступы, разделители или иные декоративные элементы между элементами списка.

- **ItemAnimator**  
  Обеспечивает анимацию при добавлении, удалении или изменении элементов списка.

- **DiffUtil**  
  Используется для сравнения элементов списка, чтобы оптимизировать процесс переиспользования `ViewHolder`.
