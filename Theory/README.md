# Theory — конспекты для подготовки к Senior Android

Теоретические конспекты (Kotlin, Android, Compose, архитектура, многопоточность,
алгоритмы, структуры данных) для подготовки к собеседованию Senior Android Developer.

- **Имена файлов и папок** — на английском (кроссплатформенно, удобно в git).
- **Содержимое** — на русском.
- **Картинки** — в папке [`images/`](images), ссылки вида `![](<images/...>)`.
- **Точка входа** — [`00 Senior Android Interview — Cheatsheet.md`](00%20Senior%20Android%20Interview%20—%20Cheatsheet.md):
  сжатая шпаргалка со ссылками на все темы.

## Цель качества
Это **единственная книга** для подготовки: каждый конспект должен не только напоминать,
но и **давать изучить тему** — определения терминов, «зачем/как», пример, грабли, вопрос-ловушка.

Прогресс доведения до этого уровня и план — в [`PLAN — Completeness audit.md`](PLAN%20—%20Completeness%20audit.md).

## Структура
Kotlin · Android · Jetpack Compose · Patterns (GoF, MV, Clean, System Design) ·
OOP · Algorithms · Data structures · IDE/Gradle · Teamwork (Git, CI/CD) ·
Cheatsheets · Growth · Pet projects.
