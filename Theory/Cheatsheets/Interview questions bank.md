Разница между IntArray и Array<Int>

У Котлина свой набор типов _kotlin.Int_, _kotlin.Long_ и т.д. И на первый взгляд может показаться, что создание объекта происходит всегда. Однако это не так. Базовые классы в стандартной библиотеке Котлина виртуальные. Это значит, что сами классы существуют только на этапе написания кода, дальше компилятор транслирует их на целевые классы платформы, в частности для JVM _kotlin.Int_ транслируется в _int_.

Kotlin-компилятор где это возможно старается использовать java примитивы, в остальных случаях ссылочные классы.

Non-null-типы компилятор котлина траслирует в примитивные Java классы платформы

_Null_-типы Котлин транслирует уже в ссылочные, т.е. _kotlin.Int? -> java.lang.Integer_

  

Для массивов из примитивов есть свои аналоги в Котлине, например, _IntArray -> int[]_ и т.д. Для всех остальных типов используется обобщенный класс Array -> T
